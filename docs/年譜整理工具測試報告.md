# 年譜整理工具（nianpu-processor）測試報告

測試日期：2026-08-04　·　工具版本：v3.14（L1 格式預分類 + L2 三錨點一致性檢查 + L3 自我進化收緊 + CBDB 生卒年核驗與年號誤配自動修正）

## 名詞說明

### 基線（Baseline）
「基線」是**歷史成功的參考值**，來自 `learnings.json` 中 `processed_files` 對每次處理的記錄（目前 **20 部**年譜有學習檔記錄）。

本次報告以**各年譜已整理完成的輸出檔**（`_已整理`／`_整理版`／`_年份切分` 等）為主要數據來源，反映「工具＋人工修正」後的實際交付狀態。三錨點數據由 `--check` 對已整理檔逐一執行（唯讀），覆蓋率以人物生卒年為錨重新計算。

### 覆蓋率（Coverage）——以「人物生卒年為錨」
覆蓋率 = **已整理檔年份標題覆蓋到的不同公元年份 ÷ 源文本記錄的年份數**，全部落在「推定出生年～年譜記載末年」區間內：

- **出生年**：三錨點多數決推定（干支＋年齡一致，出生年＝公元年 − 年齡 + 1）；無年齡格式用已知生年（紫陽 1130、魏貞庵 1616）。本次另以 CBDB 生卒年核驗（見下）。
- **年譜末年**：源文本最後一個「年齡與壽命一致」的年份；無年齡格式手動指定（紫陽 1200、方柏堂 1888）。對自訂／自編年譜，年譜可能止於卒前數年（如澄懷主人止於 1749、實卒 1755），覆蓋率衡量的是「年譜記載的一生」，見「傳主識別」一節。
- **分子**：已整理檔年份標題覆蓋的不同公元年份。每個標題依「年齡 → 干支 → 年號年」優先序推定真年——干支／年齡自洽時優先於年號年，以規避年號誤配（順治誤標崇禎、道光誤標嘉慶等）。
- **分母**：源文本落在生卒年間、以「干支＋年齡一致」或「年號＋年序＋干支」或「公元」記錄的不同年份。註文（〔〕）、引文、卷首／卷末附錄已剔除（卷首刊記如「同治二年癸亥」、身後追述多落於區間外，由區間鉗制排除）。
- **遺漏**＝分母 − 分子，即「源文本有記錄、已整理檔未覆蓋」的不同年份數。以**不同年份**計（同年多條目只計一次）。

> 本版以人物生卒年為錨的覆蓋率，取代「輸出標題 ÷ 正則偵測年份」的舊算法——後者分母正是要測的偵測能力，屬循環論證，且對純干支（魏貞庵）、無干支跨行（沈端恪）等格式失效。本定義用同一把尺子衡量全部年譜。

### 判定準則
- **✓ PASS**：年份標題 ≥ 10，且覆蓋率 ≥ 80%。
- **⚠ 注意**：年份標題 < 10（格式未被工具自動處理），或工具無法自動化（沈端恪跨行格式）。
- **⚠ 可疑標題**：三錨點（年號年→公元、干支→公元、年齡→公元）不一致，或相鄰年齡序列斷裂——人工複核點，多為源文本 OCR 錯誤或年譜自身矛盾。
