## 名詞說明

### 基線（Baseline）
「基線」是**歷史成功的參考值**，來自 `learnings.json` 中 `processed_files` 對每次處理的記錄（目前 **50 次**記錄、對應 **39 部**年譜歸檔）。本報告以「年譜整理本」清單（`年譜整理本/_清單.md`，**39 部**）為準，數據來源是各年譜**已整理的定稿檔**，反映「工具＋人工修正」後的實際交付狀態。三錨點數據由 `--check` 對已整理檔逐一執行（唯讀），覆蓋率以人物生卒年為錨重新計算。

### 覆蓋率（Coverage）——以「人物生卒年為錨」
覆蓋率 = **已整理檔年份標題覆蓋到的不同公元年份 ÷ 源文本記錄的年份數**，全部落在「推定出生年～年譜記載末年」區間內：

- **推定出生年**：三錨點多數決推定（干支＋年齡一致，出生年＝公元年 − 年齡 + 1）；無年齡格式用已知生年（紫陽 1130、魏貞庵 1616、關中李二曲 1645、焦南浦 1661、重刻鄭端簡 1499）。現代學者年譜（劉熙載、王欣夫）直接用標題顯式公元年錨點多數決。
- **年譜記載末年**：源文本最後一個「年齡與壽命一致」的年份；無年齡格式手動指定（關中李二曲 1689、焦南浦 1736）。對自訂／自編年譜，年譜可能止於卒前數年（澄懷主人止於 1749、實卒 1755），覆蓋率衡量的是「年譜記載的一生」。
- **分子**：已整理檔年份標題覆蓋的不同公元年份。每個標題依「顯式公元年 → 年齡 → 干支 → 年號年」優先序推定真年——顯式公元年（`（1666年）`）與干支／年齡自洽時優先於年號年，以規避年號誤配（順治誤標崇禎、道光誤標嘉慶、許敬菴稿本整體錯一年）。
- **分母**：源文本落在生卒年間、以「干支＋年齡一致」或「年號＋年序＋干支」或「公元」記錄的不同年份。註文（〔〕）、引文、卷首／卷末附錄已剔除。
- **遺漏**＝分母 − 分子，即「源文本有記錄、已整理檔未覆蓋」的不同年份數。以**不同年份**計（同年多條目只計一次）。

> 本次數據可重現：`python tools/nianpu_coverage.py <年譜資料目錄>`，全自動對 39 部歸檔譜逐一統計，輸出 `docs/nianpu_report_data.json`（gitignore，供重跑對照）。

### 判定準則
- **✓ PASS**：年份標題 ≥ 10，且覆蓋率 ≥ 80%。
- **⚠ 注意**：年份標題 < 10（格式未被工具自動處理），或工具無法自動化。
- **⚠ 可疑標題**：三錨點（年號年→公元、干支→公元、年齡→公元）不一致，或相鄰年齡序列斷裂——人工複核點，多為源文本 OCR 錯誤或年譜自身矛盾。

## 共識出生年回退與 L2 仲裁（v3.29 新增）

- **`_consensus_birth_year`**：以「干支＋年齡」餘類多數決（≥60％＋樣本≥5）推定出生年，年號年序多數決佐證；`--fix` 在 CBDB 缺席時回退到此共識（拔外部依賴）。許敬菴（稿本尾部整體錯一年）、尙友堂（康熙年序掉「十／二十／三十」）式「年號年序系統性誤刻」可自動修（陳紫峰「正德三年戊寅→十三年戊寅」）。
- **`nianpu_arbitrate.py`**：對 L2 衝突＋上下文，生成仲裁請求 → LLM 判斷 → 保守套用（只動年號年序與公元註記，干支／年齡／正文／前綴一律保留；修正後年號年必與干支自洽，不合即拒絕）→ 套用後復驗。
- **`slot_model.py`**（v3.19 首例、v3.29 補 `gz_age` 槽位）：把「每年譜改正則」抽象為「填槽位表」。LLM 以 schema＋few-shot 讀年譜開頭，輸出槽位 JSON（紀年形式、年齡前綴／後綴、字形變體等），工具直接套用——李恕谷式「干支＋直接年齡」小書亦可用 `--slots` 表達、與自動檢測結果一致。
