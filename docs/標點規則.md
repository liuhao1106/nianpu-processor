# 年譜古籍標點規則（加標點／斷句）

> 給 LLM 加標點時遵循的規則。目標：把「已整理但無標點」的年譜正文斷句並加標點，
> **不改動原文一個字**（只插入標點；發現 OCR 誤字可改，但必須交給 verify 供人工確認）。

## 一、標點符號與用法

全稿統一用**全形**標點：

| 符號 | 用法 | 示例 |
|------|------|------|
| `。` | 一句話說畢。判斷句尾（也／矣／焉／耳／云）、敘述句尾 | 「府君年十六，始應郡縣試。」 |
| `，` | 分句內／分句間停頓。時間、地點狀語，轉折（而／然／然則／遂／乃／於是）處 | 「九月三日，希濤生。」 |
| `、` | 並列名詞、人名／官名連排 | 「熊公諱廷弼、駱公諱駸曾尤亟以國士奇才見許。」 |
| `；` | 平行長句、對舉 | 「難人所易，而易人所難；眾皆異之。」 |
| `：` | 引出話語或列舉（云／曰／言／書云／評曰之後） | 「府君曰：「十年之後，本朝第一手也。」」 |
| `「」` | 直接引語 | 「侗初先生有「書生中安得此人」之歎。」 |
| `『』` | 引語中的引語 | 師曰：「…『…』…」 |
| `《》` | **書名**（含篇名、科考文題、書目連排） | 「著《太極圖述》一卷」「《性理大全》《近思錄》《或問》《語類》諸書」 |
| `？` | 疑問語氣（乎／耶／哉／邪／歟／與，須上下文確為疑問） | 「…其遂不可復見乎？」 |
| `！` | 感嘆（嗚呼／噫／哀哉／痛哉；文言感嘆多仍以句號收，慎用） | 「嗚呼，可痛也已！」 |
| `（）` | 注解：公元年、字號、籍貫、小注。標題內公元年保留 | 「### 同治五年丙寅（1866年）」 |

**不用**：省略號、破折號、半形標點（`,`／`.`／`?` 等一律改全形）。

**書名號判斷**（LLM 負責，需語感辨識）：文集／經注／科考文題／官府文書名（制義、四書、性理大全、近思錄、修業錄、消夏草、露花齋、千頃堂、述志賦、交友箴、兩漢及唐宋八家文讀本等）用 `《》`。難以判定是否為書名時，寧可加（過標比漏標更利於檢索），但**人名、官名、地名、年號不用書名號**。

## 二、斷句原則

1. **以句意完整為斷**：主語改變、時地轉移、事畢即斷。一時辰／一天內的多個動作以逗號連接，事敘完以句號收。
2. **時間狀語後可斷**：「三月」「秋九月」「是歲」「是年」「冬」「是年春」等後加逗號；但「是歲九月初三日酉時，府君生」此類緊接事件的不強斷。
3. **固定句式**：`評曰／評云／嘗曰／語人曰／書云／其詞曰` 後以冒號開引語；`有「…」之歎／之褒` 內嵌引語用「」。
4. **不可拆斷**：
   - 人名專稱：`府君／公／先生／先王母／先王父／先伯祖／敬輩` 及 `X公諱Y`（「諱」後是專名，不與「公」拆開斷句）。
   - 官名、地名、卷數（「《修業錄》三卷」不拆「三卷」）。
   - 年號干支日期：`康熙五年丙午`、`戊辰` 不拆。
   - 數字：`一十有七`、`千餘首`、`三十日` 不拆。
5. **引文邊界**：凡引號內的內容須在引號前開 `：「」`；引文結束後續「云／如此／者也」等按原文位置放引號外或內，以文意為準。
6. **詩賦箴**：不逐句硬斷。四言箴／賦可按對仗與韻腳以句號收、逗號中停；「賦曰：」「箴曰：」後另行或接排均可，但全稿一致。焦南浦定稿中賦以句號斷句、箴以四字一句句讀。
7. **年份標題行（`### …`）不改動**：除標點外一個字都不許改，標題中已有的 `（1866年）` 括號照留。
8. **季節標記**：`**春**／**夏四月**` 等 `**…**` 行不改動。

## 三、質量控制

1. **字符保全**：全程只插入標點。不增字、不删字、不改字。
2. **OCR 誤字**：標點時若發現明顯 OCR 誤字（如 `一十→二十`、`葢→蓋`、`干里→千里`、`虢→號`），可以改，但**每改一處都要在該塊檔尾記成 HTML 註解** `<!-- 改字記錄：原文→改文（出處） -->`，`--merge` 會自動剝除註解、`--verify` 會把改動列為內容差異供人工核對。
3. **半形改全形**：輸出不得有 `, . ? ; :` 半形標點。
4. **成對性**：引號、書名號、括號必須成對。

## 四、工作流

```
已整理.md ──chunk──> pun_01.md … pun_08.md ──LLM 逐塊加標點──> 標點塊
   └──merge──> 定稿.md ──verify──> 字符保全校驗報告 → 人工審核內容差異
```

1. `python nianpu_biaodian.py --chunk <已整理.md>` → 按年份塊切分。
2. LLM 依本規則逐塊加標點（直接編輯 pun_XX.md，改字記錄寫在檔尾）。
3. `python nianpu_biaodian.py --merge <已整理.md>` → 合併並自動 verify。
4. `python nianpu_biaodian.py --verify <已整理.md> <定稿.md>` → 重新比對。
5. 人工審核 verify 報出的「內容差異」（即標點時順手改的 OCR 誤字）。

## 五、示例

未標點：

```
同治五年丙寅（1866年）
九月三日希濤生時我父霓孫府君需次浙江僦居杭州省城中板兒巷之董氏宅大母孫太夫人迎養在寓希濤生小名鶴齡前三年長兄延齡生而不育希濤乃居長是年我父年三十一我母秦太夫人年三十
```

標點後：

```
### 同治五年丙寅（1866年）

九月三日，希濤生。時我父霓孫府君需次浙江，僦居杭州省城中板兒巷之董氏宅，大母孫太夫人迎養在寓。希濤生，小名鶴齡。前三年長兄延齡生而不育，希濤乃居長。是年，我父年三十一，我母秦太夫人年三十。
```

（注：`### ` 標題行本身在 chunk 中就存在，LLM 不重打 `###`，只標點正文；此例是為展示斷句效果。）
