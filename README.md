# 年譜整理工具 / nianpu-processor

一鍵處理原始古籍刻本 OCR 後的中國年譜文本、或從識典古籍等下載的年譜文本，自動按年份切分、補全年號、整理段落。支援明清兩代及南明年號，並已擴展至公元年號/民國紀年的近現代年譜（民國以後），具備自我進化能力。

本工具旨在為中國歷史人物、思想史、哲學史、學術史研究搭建數字基礎文本——將結構混亂的年譜原始文本轉化為結構清晰、可由 AI Agent 自動識讀的 Markdown 格式，便於後續搭建 RAG 知識庫、進行大規模文本分析與哲學史、思想史、史學研究。

## 功能

- **年份標題化** — 將 `八年己巳，先生年五十二` 轉為 `### 八年己巳，先生年五十二`
- **公元年標註** — 在標題干支後自動標註公元年：`### 嘉慶十一年丙寅（1806年）`，依 `REIGN_START_YEARS` 年號元年換算
- **公元年號/民國格式** — 近現代年譜：`公元一八七三年，同治十二年，岁次癸酉，一岁` → `### 公元一八七三年（1873年），同治十二年，岁次癸酉，一岁`（涵蓋光緒/宣統/民國，支援 廿/卅）
- **年號補全** — 自動追蹤當前年號，對無年號的條目標題補上年號
- **OCR 容錯** — 自動修正常見 OCR 錯誤（`先元年`→`先生年`、`十年九歲`→`十九歲` 等）
- **年號字形正規化** — `光緖`→`光緒`、`萬厯`/`萬厤`→`萬曆`、`永厯`→`永曆`
- **月份/季節分段** — 每一年內按 `春/夏/秋/冬` 拆分，以 `**春正月**` 標記
- **嵌入式年份拆分** — 合併後段落中二次掃描隱藏的密集年份（如 `八年戊子五歲。九年己丑六歲`），支援行首出現、一行多處匹配，並自動沿用前一年號補全
- **跨年邊界檢測** — 合併斷行時檢測年份邊界，防止不同年份誤合
- **自我進化 v3** — 每次處理後自動發現新年號、新字形、新前綴，含置信度評分和假陽性過濾
- **從修正中學習** — 手動修正後的結果會反饋到學習系統，自動標記無效學習
- **審查清理** — `--prune` 命令批量移除已被標記為無效的學習
- **檢查報告** — 處理完成後自動比對原始文本，報告遺漏年份、年齡空缺、年號切換

| 直接年齡 | `十九年甲戌七嵗` | 萬清軒先生年譜 |
| 年N嵗 | `二十三年癸卯，年二十六` | 方柏堂變體 |
| 公年N歲 | `十八年辛丑，公年十有一` | 張清恪公年譜 |
| 跨行年份+年齡 | `康熙十六年\n公七歲` | 沈端恪公年譜 |
| 出生條目 | `仁宗睿皇帝嘉慶十三年戊辰八月二十四日先生生` | 通用 |
| 出生日期（無生字） | `明萬厯四十六年戊午十一月二十一日辰時` | 施愚山先生年譜 |

| 明代年號 | `明萬厯四十七年己未，先生一歲` | 明代年譜 |
| 年月日前綴+生於 | `康熙十一年壬子，是年九月初九日辰時，生於京師` | 澄懷主人自訂年譜 |

| 出生日期+人名+生於 | `嘉慶十一年丙寅十月一日戌時。兆鏞生於…` | 殷譜經侍郎自定年譜 |
| 公元年號/民國 | `公元一八七三年，同治十二年，岁次癸酉，一岁` / `公元一九五零年，岁次庚寅，七十八岁` | 項蘭生自訂年譜 |
| 民國年號 | `公元一九一二年，民國元年，岁次壬子，四十岁` / `公元一九四七年，民国卅六年，岁次丁亥，七十五岁` | 項蘭生自訂年譜 |
| 無年齡純年份 | `紹興元年辛亥` / `四年甲寅` / `孝宗隆興元年癸未` / `光宗紹熙元年庚戍` | 紫陽文公先生年譜 |

## 公元年標註

處理完成後，會在所有含年號+年序的標題干支後自動標註公元年：

```
### 嘉慶十一年丙寅（1806年）十月一日戌時
### 道光三十年庚戌（1850年）四十五歲
### 光緒元年乙亥（1875年），年七十歳
```

換算方式：`公元年 = 年號元年公元 + 年序 - 1`（如 咸豐八年 = 1851 + 8 - 1 = 1858）。

年號與元年的對應表存在 `REIGN_START_YEARS` 配置（含異體字 萬厯/萬曆、光緖/光緒 等），涵蓋宋代、元代、明代（含南明）、清代、清末宣統、民國百餘個年號。年號不在表中、或標題只有干支無年序（如「丙申，公四十一嵗」）時，保持原樣不標註。

**公元年號標題本身也會標註阿拉伯數字**：`### 公元一八七三年（1873年），同治十二年，岁次癸酉，一岁`（依中文數字逐位轉換，如 一八七三=1873、一九五零=1950）。

## 處理流程

```
讀取檔案
  → 年號字形正規化（光緖→光緒）
  → OCR 錯誤修正（先元年→先生年）
  → 合併跨行年份+年齡（沈端恪格式支援）
  → 查找年份標記（前綴 + N年干支 + 先生N歲 / 直接N歲 / 澄懷主人無稱謂格式）
  → 插入 ### 標題
  → 追蹤並補全年號
  → 合併斷行（含跨年邊界檢測）
  → 嵌入式年份二次掃描（密集年份拆分）
  → 按月份/季節分段（**春正月**）
  → 輸出
  → 自動檢查報告
  → 自我進化學習
```

## 演算法說明

### 年份匹配

腳本使用多層正則匹配，按優先級依次嘗試：

1. **`ad_entry`** — 公元年格式：`公元一八七三年，同治十二年，岁次癸酉，一岁`（3-4位中文數字，可選年號年+岁次干支，年齡後綴必備避免誤切世系）
2. **`birth`** — 出生條目：`[前綴]N年[干支]...先生生`
3. **`entry_sb`** — 有干支的年份（附稱謂）：`[前綴]N年干支 + [最多120字] + 先生N歲`
4. **`entry_no_sb`** — 無干支但年號明確：`[前綴]年號N年...先生N歲`
5. **`birth_no_person`** — 無稱謂出生條目（澄懷主人風格）：`康熙十一年壬子，是年...生於京師`
6. **`entry_sb_no_person`** — 無稱謂直接附年齡（澄懷主人風格）：`十二年癸丑二歲` / `十年，壬子六十一歲`

中間文字長度限制在 120 字（v2 從 60 字放寬），適應長註文年譜。合併斷行後另有嵌入式年份二次掃描，捕捉密集年份。

**v3.1 改進：**
- `birth`/`entry_sb`/`entry_no_sb` 中間文字改用 `[^。\n]`，不跨句號，防止一個條目吞噬其後真實年份並污染年號追蹤（根因：`birth` 誤把「爲公生朝」當出生）
- `birth_no_person` 與 `is_birth` 判斷加 `(?<!先)`，避免「先生於」內含的「生於」子字串被當成出生
- `entry_sb_no_person` 容許「N年。干支N歲」斷裂格式（如「十年。乙丑十五歲」）
- `entry_sb_direct` 要求干支後必須有標點，避免把「乙丑春」誤判為年份條目

**v3.2 改進（據殷譜經侍郎自定年譜經驗）：**
- `entry_sb_no_person` 新增可選「年」前綴，支援「光緖元年乙亥，年七十歳」格式
- 新增 `AGE_SUFFIX_REQUIRED`：無稱謂直接年齡格式的年齡後綴必備，避免「嘉慶十一年丙寅十**月**」的「十」被誤當年齡、嵌入式拆分把「同治十一年壬申**六**月」的「六」誤切為標題
- `birth_no_person` 容許跨一句號，支援「{年號}年干支{月日時}。{人名}生於」出生條目（殷譜經風格）
- `verify_output` 比對前先正規化年號字形（光緖→光緒），避免字形變體誤報遺漏

### 年號補全

處理器追蹤最近一次的年號。當遇到 `二年乙酉，先生二十七歲` 這樣無年號的條目時，會自動補上當前年號變為 `順治二年乙酉，先生二十七歲`。

### 自我進化 v3

每次處理完成後，系統會自動分析文本發現：
- **新年號** — 文本中出現但不在已知列表的年號（如「洪武」「永樂」），含置信度評分（< 0.4 不自動應用）
- **新前綴** — 「X皇帝+X年號」的新組合（含標點片段被自動過濾）
- **字形變體** — 年齡後綴的罕見字形（非單字或形近字被自動過濾）

發現的知識存入 `learnings.json`，同一年號出現 ≥2 次且置信度 ≥0.4 後自動應用到後續處理。

**v3 新增：**
- **置信度評分**：新年號自動計算置信度（0.0~1.0），含頻率、字元品質、上下文等多維評分
- **假陽性過濾**：純數字年號（如「一十」「二十」）、含標點前綴（如「過人遠矣。宣宗成皇帝」）、多字符字形（如「王歲」）在發現階段即被拒絕
- **從修正中學習**：透過 `_record_correction()` 記錄手動修正，自動標記對應學習為無效
- **審查清理**：`python nianpu_processor.py --prune` 批量移除已被標記為無效的學習
- **去重**：同一檔案重複處理時更新而非追加記錄

## 常見問題

**Q: 輸出亂碼？**

A: 確認輸入文件為 UTF-8 編碼。若非 UTF-8，腳本會自動嘗試 GBK/Big5。

**Q: 年份未被切分？**

A: 可能原因：
- 年份與年齡相隔超過 120 字（中間有超長註文）
- 缺少干支且無年號前綴
- 使用的年號不在支援列表中（自我進化系統可自動發現）
- OCR 錯誤導致年份模式無法匹配（如「先元年」→工具已內建修正）

**Q: 某個年份被誤切？**

A: 註文中的年份+年齡組合（如「按武夷先生卒於丁亥，年七十八」）因不含干支且「年七十八」格式不匹配 `先生N歲`，一般不會誤切。若仍有誤匹配，可調整 `entry_sb` 的 120 字限制。

**Q: 光緖和光緒有什麼區別？**

A: 兩者是同一年號的不同字形（緖=緒的異體），工具會自動將 `光緖` 正規化為 `光緒`。

**Q: 首年正文開頭漏了「生於」/「生于」/「生」等字？**

A: 這是把出生日期併入標題（`### 嘉慶十一年丙寅十月一日戌時`）時常見的誤刪。標題只該「借用」日期顯示，正文的出生句（`{名}生於{地}`）必須原樣保留。整理首年後，檢查正文首句是否仍以「{名}生於/生于/生/誕」開頭——若正文直接以地點（如「平望鎭東溪湖第時…」）或家屬年齡開頭，即為漏刪，應對照原稿補回人名+動詞。

- **年號延續陷阱**：崇禎十七年甲申條目內文出現「即大淸順治元年」，年號切換藏在正文而非條目開頭，致其後無年號條目（「二年乙酉三十三歲」等）誤沿用崇禎年號、公元年全錯。人工修正：依干支換算（乙酉=1645=順治二年），補上順治十七年，並修正康熙十九/二十年（誤標為崇禎十九/二十年）
- **季節複合詞誤切**：秋闈（鄉試）、春日、春秋之法（《春秋》）、春仲（仲春）、冬至（節氣）被誤切為季節標記，人工還原
- **出生/卒年條目**：「萬厯四十一年癸丑五月二十八日生一歲」「康熙二十一年壬戌正月初九日卒。七十歲」補為標題（出生日期與「一歲」間隔「生」字、卒年年齡在句號後跨句，原工具未切分）
- **learnings.json 更新**：新增 2 條修正記錄、3 條經驗教訓，清理垃圾候選年號（人十/以五十/至一八九）


### v3.6（公元年號/民國格式，擴展至民國以後）

- **公元年號格式**：新增 AD 模式 `公元一八七三年，同治十二年，岁次癸酉，一岁` → `### 公元一八七三年（1873年），同治十二年，岁次癸酉，一岁`（`_build_full_pattern` 新增 `ad_entry` 分支，AD年=3-4位中文數字，可選年號年+岁次干支，年齡後綴必備避免誤切世系）
- **公元年標註**：`annotate_ad_years` 對 `### 公元N年` 標題依中文數字逐位轉阿拉伯數字標註（一八七三=1873、一九五零=1950），新增 `_chinese_digits_to_int`
- **年號擴充**：`REIGNS`/`REIGN_START_YEARS` 新增 光绪（簡體）、宣統/宣统（1909）、民國/民国（1912）
- **簡體「岁」後綴 + 廿/卅**：`AGE_SUFFIXES` 加 `岁`，`AGE_DIGITS` 加 廿/卅，`_build_year_pattern` 加 廿一~廿九/卅一~卅九，`_chinese_year_to_int` 支援 廿/卅
- **4位公元年防誤切**：`_build_year_pattern` 年份前加 `(?<![一二三四五六七八九零〇])` 否定後顧，防止「一八七三年」中的「三」被誤當年份
- **年號提取**：`extract_reign` 對 `公元` 標題在標題中段查找年號，`insert()` 對公元標題不補上前一年號
- **驗證**：`verify_output` 識別 AD 格式、公元標題不報「缺年號」、`chinese_num_to_int` 支援 廿/卅

### v3.5（宋/元/明年號擴充）

- **年號擴充**：`REIGNS` 新增宋代（建隆～祥興 56 個）、元代（中統～至正 14 個）、明代（洪武～崇禎 17 個）、南明（弘光）年號，支援整理宋元明人物年譜
- **公元年標註擴充**：`REIGN_START_YEARS` 對應補上宋/元/明年號元年→公元年（如 建隆元年=960、紹興元年=1131、洪武元年=1368、永樂元年=1403）

### v3.4（首年出生句保留規則）

- **首年出生句必須保留動詞**：年份標題只「借用」日期，正文「{名}生於/生于/生/誕{地}」須原樣保留，不得因日期已入標題而刪去開頭人名+動詞（如殷譜經年譜漏「兆鏞生於」）
- **新增常見問題**：首年正文開頭若直接以地點或家屬年齡起頭，即為漏刪「生於/生」等字，需對照原稿補回
- **learnings.json 新增 lesson**：記錄此類首年誤刪的根因與檢查方法

### v3.3（公元年標註）

- **公元年標註**：在標題干支後自動標註公元年（`### 嘉慶十一年丙寅（1806年）`），換算自 `REIGN_START_YEARS` 年號元年公元表（含 萬厯/萬曆、光緖/光緒 等異體字形）
- **中文數字年序轉換**：`_chinese_year_to_int` 支援 元/一~九/十/十一~十九/二十~九十九/十有一 等寫法
- 無年號或無年序的標題（如純干支「丙申，公四十一嵗」）保持原樣，不標註公元年

### v3.2（據殷譜經侍郎自定年譜經驗）

- **無稱謂直接年齡的「年」前綴變體**：`entry_sb_no_person` 支援 `光緖元年乙亥，年七十歳`（干支後可帶 `年` 再接年齡），也支援 `五年。丙寅六十一歲` 的句號分隔
- **年齡後綴必備（`AGE_SUFFIX_REQUIRED`）**：無稱謂格式改為年齡後綴必備，杜絕把「嘉慶十一年丙寅**十**月」的「十」誤當年齡、以及嵌入式拆分把「同治十一年壬申**六**月」的「六」誤切為標題的 bug
- **出生條目跨句號**：`birth_no_person` 容許「{年號}年干支{月日時}。{人名}生於」跨一句號，支援自定年譜「嘉慶十一年丙寅十月一日戌時。兆鏞生於…」出生條目
- **驗證比對正規化**：`verify_output` 比對前先 `_normalize_reign_variants`，避免「光緖/光緒」字形變體導致已處理年份誤報遺漏

### v3.1（據警石府君年譜經驗）

- **嵌入式年份拆分升級**：`_split_embedded_years` 支援行首出現、一行多處匹配，並自動沿用前一年號補全（解決「十七年壬申二十二歲」「二年壬午三十二歲」等漏切）
- **主正則不跨句號**：`birth`/`entry_sb`/`entry_no_sb` 中間文字改用 `[^。\n]`，防止一個條目吞噬其後真實年份並污染年號追蹤（根因：`birth` 誤把「爲公生朝」當出生）
- **「先生於」防誤判**：`birth_no_person` 及 `is_birth` 判斷加 `(?<!先)`，避免「先生於」內含的「生於」子字串被當成出生
- **「N年。干支N歲」斷裂格式**：`entry_sb_no_person` 容許 `。` 分隔（如「十年。乙丑十五歲」）
- **`entry_sb_direct` 收緊**：干支後必須有標點，避免把「乙丑春」誤判為年份條目
- **Windows 編碼修復**：`main()` 開頭將 stdout/stderr 重設為 UTF-8，解決中文亂碼與 `--status` 空輸出
- **基本操作規則**：SKILL.md 新增操作規則，要求每次改進腳本/學習檔案後同步更新 README

### v3（自我進化升級）

- **置信度評分系統**：新年號自動計算置信度（0.0~1.0），低於 0.4 的不自動應用
- **假陽性過濾**：純數字年號（一十、二十等）、含標點前綴、多字符字形在發現階段被拒絕
- **從修正中學習**：`_record_correction()` 記錄手動修正，自動標記對應學習為無效
- **審查清理**：`--prune` 命令批量移除已被標記為無效的學習記錄
- **去重記錄**：同一檔案重複處理時更新而非追加
- **修正日誌**：追蹤每次修正的錯誤→正確映射
- **自我進化報告增強**：區分有效/無效學習、顯示置信度條、最近修正記錄
